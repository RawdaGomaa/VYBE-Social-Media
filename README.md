# VYBE – Social Media Platform 🚀

A modern social media web application built using React, TypeScript, and Vite.

## 🌟 About The Project

VYBE is a social media platform designed to provide users with an interactive and engaging online experience.

The project focuses on modern UI design, reusable components, application routing, and responsive front-end development.

## ✨ Technologies Used

- React.js
- TypeScript
- JavaScript
- HTML5
- CSS3
- Vite

## 🚀 Getting Started

To run the project locally:

1. Clone this repository:

```bash
git clone https://github.com/RawdaGomaa/VYBE-Social-Media.git
```

2. Navigate to the application folder:

```bash
cd VYBE-Social-Media/social-app
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL provided by Vite.

## 🏗️ Production Build

```bash
npm run build
```
